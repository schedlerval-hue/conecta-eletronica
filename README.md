# Portal Educacional - Conecta Eletrônica

Projeto de software desenvolvido para a disciplina de Eletroeletrônica, com o objetivo de abrigar conteúdos informativos e interativos sobre componentes e circuitos eletrônicos.

## 🚀 Tecnologias Utilizadas
- **HTML5**: Estruturação semântica e acessível das páginas.
- **CSS3**: Estilização responsiva, layout modular e design system.
- **JavaScript (ES6)**: Lógica interativa para o Quiz de fixação de conteúdos.

## 📂 Estrutura do Projeto
- `index.html`: Página principal com a visão geral do portal e acesso ao Quiz.
- `diodos.html`: Módulo sobre Diodos e Retificação.
- `tbj.html`: Módulo sobre Transistores Bipolares de Junção (TBJ).
- `mosfets.html`: Módulo sobre Transistores de Efeito de Campo (MOSFETs).
- `circuitos-integrados.html`: Módulo sobre Circuitos Integrados (CIs).
- `css/style.css`: Folha de estilos centralizada.
- `js/script.js`: Scripts de interatividade.
